# 项目问题记录

## 2026-08-05：业主ID不能为空
- **接口**：POST /api/owner/orders?ownerId=1
- **报错**：业主ID不能为空
- **原因**：`RepairOrder` 类中 `ownerId` 字段有 `@NotNull` 校验，但请求体未传该字段
- **解决**：请求体中加入 `"ownerId": 1`

## 2026-08-05：Redis序列化报错
- **报错**：`ClassNotFoundException`
- **原因**：`RedisTemplate` 默认使用JDK序列化，对象未实现 `Serializable`
- **解决**：改用 `StringRedisTemplate` + Jackson 手动JSON序列化
